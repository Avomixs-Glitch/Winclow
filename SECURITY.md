# Politique de sécurité

La sécurité de Winclow est prise au sérieux. Si vous identifiez une vulnérabilité concernant le produit public, évitez de la publier dans une issue ouverte.

Utilisez plutôt le formulaire de contact disponible sur [winclow.com](https://winclow.com) en indiquant clairement « Security report » dans votre message. Incluez, si possible, une description du problème, son impact potentiel et des étapes de reproduction minimales.

Nous accuserons réception du signalement et l’évaluerons de manière confidentielle.

Ce dépôt ne contient pas le code source de l’application ni ses secrets d’exploitation.
