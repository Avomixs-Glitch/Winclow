# Contributing to Winclow

Thank you for taking an interest in Winclow.

This is a public product showcase, not the application source repository. The most valuable contributions here are clear product feedback, accessibility observations, documentation corrections and partnership enquiries.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Keep the report focused on a single topic.
- Do not share credentials, account data, personal information or security-sensitive details.
- For a suspected vulnerability, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## What makes useful feedback

Explain the player problem, the current experience, the expected outcome and—when appropriate—the browser or device context. Screenshots are welcome only when they contain no personal or account information.

## Scope

Pull requests that change product source code cannot be accepted here because the application implementation is private. Documentation corrections and presentation improvements may be considered when they are accurate, focused and consistent with the product voice.

By participating, you agree to keep the conversation constructive, respectful and privacy-conscious.
